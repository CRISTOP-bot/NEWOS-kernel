# NEWOS kernel

This is the kernel and low-level machine-code component of [NEWOS](https://github.com/CRISTOP-bot/NEWOS).

Contains ABI headers and implementation, architecture code, core, cryptography, device drivers, filesystems, IPC, kernel library, memory manager, networking, process/scheduler, system services, and syscall implementation. The superproject uses symlink shims so these paths remain available at their original top-level locations.
